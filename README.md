# Derivatives Pricing Engine

A Python library implementing and validating quantitative models for derivatives pricing.
Built as a hands-on portfolio project covering Black-Scholes, Monte Carlo, binomial trees, Greeks, implied volatility and exotic payoffs.

## Documentation

Model theory, formulas, assumptions and worked examples live in [`docs/`](docs/):

- [Black-Scholes](docs/black_scholes.md)

Each model also has a verification notebook in [`notebooks/`](notebooks/).
