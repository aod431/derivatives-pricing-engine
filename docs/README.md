# Documentation

Each document explains one model: the idea, the formulas, a worked example with numbers from the code, where it fails, and a few interview questions at the end. The notebooks reproduce the numbers.

## Suggested reading order

1. **Maths first (optional but useful):** [foundations](foundations.md): Brownian motion, Ito, risk-neutral pricing, put-call parity.
2. **Basics:** [Black-Scholes](black_scholes.md), then [Greeks](greeks.md), then [implied volatility](implied_vol.md).
3. **Numerical methods:** [Monte Carlo and QMC](monte_carlo.md), [binomial trees](binomial.md), [PDE](pde.md), [Greeks by Monte Carlo](mc_greeks.md).
4. **Smile and surface:** [Heston](heston.md), [SABR](sabr.md), [SVI and no-arbitrage](svi.md).
5. **Products and risk:** [Asian options](exotics.md), [barrier options](barrier.md), [American options (LSM)](american_lsm.md), [delta hedging](hedging.md).
6. **Revision:** [interview cheat sheet](interview_cheatsheet.md).

## Which method for what

| If you need... | Use | Why |
|---|---|---|
| A European vanilla price | Black-Scholes | Exact and instant |
| An American option, one underlying | Tree or PDE | Early exercise is a backward problem |
| A path-dependent payoff | Monte Carlo | No closed form, error falls as 1/sqrt(N) |
| A smile | Heston, SABR or SVI | Black-Scholes has one flat vol |
| Greeks of a complicated payoff | Pathwise or likelihood ratio | Bumping is noisy |
